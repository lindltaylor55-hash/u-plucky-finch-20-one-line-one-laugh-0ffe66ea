An entry for the [One Line, One Laugh](https://make.fun/bounty/u-plucky-finch-20-one-line-one-laugh-0ffe66ea) competition on [make.fun](https://make.fun): a single funny line, at most 200 characters, written to `/output/entry.txt` by `main.ts`.

> I asked my smart speaker to play something relaxing and it said "have you tried turning yourself off and on again".

Run it with `node main.ts` (Node 22, standard library only). Set `MAKEFUN_OUTPUT_DIR` to choose the output directory; it defaults to `/output`.
